# 封闭式提示词打法（生成型批量任务）

高质量提示词 → 单轮命中：把不确定性压到最低，AI 首答即终稿。

1. **六要素一次打包**：任务 + 业务语义 + 量化约束（≤N 字/每列一句话/3-8 个）+ 封闭清单（表名+全列名一次给全）+ 输出格式（"只输出 YAML"）+ 占位符模板（`alias: <中文别名>`，缺省省略规则）
2. **输出格式硬约束**：显式加"不要 Markdown 代码围栏"；量化口径写死（中文按字、ASCII 按词、空格不计）
3. **反幻觉三件套**：先读真值文件再作答；事实编号白名单（F1/F2…，禁止引用未提供编号）；无法证实标 `[推测]`/`（待确认）`
4. **分批 + 小样验收 + 缩小粒度重试**：列说明类每批 ≤10~15 表（别名可 50+），先 3~5 张验格式；整批失败 → 缩小到单表重试，不原样重发；空响应写"从 XX 继续，只输出未生成部分"
5. **程序化校验闭环**：脚本断言 YAML 可解析、无围栏、字数 ≤N、输出集合与输入清单差集为空、术语数量在界内
