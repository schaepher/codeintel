# AI 成本与工具纪律护栏

1. **成本预算三段式**：声明"预计 N 次、预算 X" → fake CLI/--dry-run 单条验证 → 全量仅验收跑一次
2. **批量优先 + 同会话 resume**：分散需求清单化合并成一次请求，上下文用 resume 复用——批量一次调用完成，逐条调用超时失败率高；分批是降级手段不是默认，主动确认度量维度（条数 vs token 上限）
3. **工具纪律**：白名单内用工具（不虚构工具名）；自包含任务禁止查库；同一工具连续失败 2 次即降级（`echo hello` 都失败 → 判定环境不可用，基于已有信息输出并标注置信度，失败信息只记日志不作回复正文）；引用文件必须在工作目录内（外部先 cp），不可读时上报原因不编造
4. **降级路径**：如实声明 → 按成本排序列替代通道 → 基于已有信息输出 + 标注置信度 → 条件恢复后补齐
