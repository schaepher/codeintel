## 测量边界

- cold_first_query = 该 (N) 库上本轮的第一次查询；其余 warm_repeat。未 drop OS page cache（无权限），且夹具刚由 SaveBatchStats 写入——故 cold 仅表示“该库首个查询进程”，不代表冷 OS 缓存；每样本都是新进程（SQLite 连接级缓存必冷）。
- query_ms 含 QueryContext + 全部 Rows.Next/Scan + rows.Close 之前；rss_before_bytes 是查询前 RSS（不是查询增量）；max_rss_bytes 是进程峰值 RSS；temp_peak_bytes 是查询全生命周期内 TMPDIR 下打开文件大小之和的峰值。所有变体使用同一构建配置（同一测试二进制、同 DSN）。
- 临时文件峰值 0 表示“采样覆盖全查询生命周期且始终未出现落盘临时文件”（SQLite 页缓存足够），不是采集失败。
- 本夹具是 SQL 资源机制夹具（N=256/4096，3N 条边），不是完整源码 init，也不代表真实大仓（如百万节点）的绝对值。
